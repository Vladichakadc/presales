Referencia · Topologías y Arquitecturas

Guías de
Diseño de Red

Topologías de referencia para WAN, SD-WAN, MPLS, datacenter y seguridad perimetral.

Hub & Spoke (Estrella)

┌──────┐ │ HUB │ └──┬───┘ ┌─────┼─────┐ ┌──┴──┐┌─┴──┐┌─┴──┐ │ BR1 ││BR2 ││BR3 │ └─────┘└────┘└────┘

Todo el tráfico pasa por el hub central. Ideal para centralizar seguridad e inspección.

  • Ventaja: control centralizado, fácil de gestionar
  • Desventaja: punto único de fallo, latencia branch-to-branch alta
  • Equipos hub: AR6700/AR8700, Catalyst 8500, FortiGate 600F+

Full Mesh / Parcial Mesh

┌──────┐ ┌──────┐ │ R1 │───│ R2 │ └──┬───┘ └──┬───┘ │ ╲╱ │ │ ╱╲ │ ┌──┴───┐ ┌─┴────┐ │ R3 │───│ R4 │ └──────┘ └──────┘

Cada nodo conecta con todos los demás. Máxima resiliencia y mínima latencia.

  • Ventaja: redundancia total, baja latencia E2E
  • Desventaja: costos O(n²) en circuitos, complejidad de gestión
  • Equipos: NE8000 M4+, ASR 9000, Nokia 7750 SR-s

SD-WAN Overlay

┌────────────────────┐ │ ORQUESTADOR │ └──────┬─────────────┘ ┌────┴────┐ │UNDERLAY │ MPLS + Internet └────┬────┘ ┌──────┼──────┐ ┌─┴──┐┌─┴──┐┌─┴──┐ │CPE1││CPE2││CPE3│ └────┘└────┘└────┘

Túneles cifrados sobre Internet y/o MPLS con selección dinámica de path.

  • Ventaja: reducción costos MPLS, visibilidad de aplicaciones, ZTP
  • Desventaja: calidad depende del underlay
  • CPE: AR5710-S, Catalyst 8200, FortiGate 60F/100F

MPLS L3VPN (PE-CE)

CE1──PE1──P──PE2──CE2 │ PE3 │ CE3

VPN de capa 3 sobre red MPLS del proveedor con separación por VRF.

  • Ventaja: QoS garantizado, aislamiento multicliente robusto
  • Desventaja: costos mensuales, dependencia del ISP
  • Equipos PE: NE8000 M8+, ASR 9000, Nokia 7750 SR-7s

Internet Breakout + SASE

┌─────┐ ┌──────────┐ │ CPE ├────│ SASE PoP │ └──┬──┘ └─────┬────┘ │ ┌───┴───┐ │ │ CLOUD │ ┌──┴──┐ └───────┘ │ LAN │ └─────┘

Tráfico SaaS/cloud directo desde la sucursal, seguridad en la nube (SASE/SSE).

  • Ventaja: experiencia óptima para M365, Salesforce, SaaS
  • Desventaja: requiere seguridad distribuida confiable
  • Equipos: FortiGate + FortiSASE, Catalyst 8300 + Umbrella

Leaf-Spine (Datacenter)

┌──────┐ ┌──────┐ │SPINE1│ │SPINE2│ └─┬┬───┘ └───┬┬─┘ │╲╲ ╱╲ ╱╱ │ │ ╲╲╱ ╲╱╱ │ ┌─┴──┐ ┌──┴─┐ │LEAF1│ │LEAF2│ └─────┘ └─────┘

Topología no bloqueante. Cada leaf conecta a todos los spines, latencia predecible.

  • Ventaja: escalabilidad horizontal sin bloqueo
  • Desventaja: alto cableado, requiere automatización (EVPN-VXLAN)
  • Spine: Arista 7500R3, QFX10002, NE8000 F8
