# 2026-11-01 · PR #104 · Entregas: el resumen nombra las mal formadas que no muestra

- **Encargo:** mejora aprobada por el dueño al cerrar el PR #101 («Implementar esa mejora»).

## Cerrado

El arranque enseña las tres últimas entregas (`scripts/entregas.js --n=3`, PR #101). Si una entrega mal formada más vieja hacía saltar el aviso, no se sabía cuál era sin correr `npm run entregas -- --todas`. Ahora `resumen()` añade «Mal formadas fuera de las mostradas (N)», con el archivo y el motivo de cada una. Sin ninguna rota fuera de la vista, no añade nada; con `--todas` no lo repite. `test/entregas.test.js` prueba los tres casos y se pone en rojo si se quita el aviso.

## Estado

Nada pendiente de este tema. **Criterio que conviene conservar**: un aviso que resume más de lo que enseña dice siempre de qué se trata (archivo y motivo), no solo que algo falla.
