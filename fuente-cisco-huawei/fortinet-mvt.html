The values in this table are the hard-coded maximum values. They may not be practical limits for every situation and are not a promise of performance.

For a complete table for your unit, run print tablesize on the CLI.

Global limits
limits

A global limit is the ceiling for the whole device — every administrative domain shares it. A limit applies inside a single domain, so the device total scales with how many you have configured.

Where an object has both, the table shows the global one, because that is the ceiling you actually reach first.

Legend How to read this table
print tablesize Live values on the device CLI
Global limit Applies to the entire .
limit Applies to a single .
0 No hard limit Limited only by system memory.
INT Interface-bound Equals total physical + virtual interfaces.

About this tool

Reading the Maximum Values Table

The table compares hard-coded firmware ceilings across one or more models for a specific software version. Cells show the maximum the kernel will accept — not a recommended capacity. Real-world capacity depends on memory, CPU, traffic profile, and feature mix.

  1. 01

    Pick a product family &amp; version

    Each firmware release ships with its own set of compiled limits. The dropdowns are scoped so you only see versions and models that exist for the selected family.

  2. 02

    Add the models you want to compare

    Each chosen model becomes a column. Add as many as you need — the table scrolls horizontally for wide comparisons.

  3. 03

    Read the row colors

    Black rows are global limits — they apply to the whole config. Lavender rows are per-domain limits. The legend summarizes the special glyphs.

  4. 04

    Search or paginate

    Use the search box to jump to a specific object (e.g. "ipsec", "policy"), or page through the full list. Selections persist across searches.

Important caveats

  • These are maximums, not promises. Sustained throughput depends on memory and feature load.
  • Per-domain ceilings scale with the number of domains available on your device.
  • Some objects show 0 or INT — see the legend.
