Starting with AOS-8.13.0.0 IPSec tunnels can be set to require PPK configuration on the initiator and responder.

This feature can be enabled by running the crypto-local isakmp ppk-mandatory command on the responder. When ppk-mandatory is enabled, both the responder and initiator are expected to have the PPK configured. Otherwise, the tunnel will not come up. The ppk-mandatory parameter will not have any effect if it is enabled on the initiator, it is applicable only on the responder. Supported deployments:
