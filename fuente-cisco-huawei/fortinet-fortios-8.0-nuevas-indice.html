New Features

  • Overview
  • GUI
    • General usability enhancements
      • Summary panel in Log Details
      • GUI support for preferred outbound route map options
      • Seven-day setup period for GUI and CLI configuration
      • VDOM selection for Central Management in the GUI
      • GUI support for configuring proxy ARP on VLAN interface
      • Improve switch management
      • Display Known Exploited Vulnerabilities from FortiClient
      • Custom GUI themes and admin‑level personalization
      • Enhanced GUI support for Inline-CASB SaaS Application
      • Enhance Security Fabric topology performance with lazy loading
      • Dashboard and monitor unification
      • Feature Visibility page redesign 8.0.1
      • GUI notification center for hardware and operational alerts 8.0.1
    • FortiView
      • Graphical display for application performance monitoring analytics
      • Interactive FortiView Applications and AI Applications dashboards 8.0.1
  • Network
    • General
      • IPv6 Multicast Routing Enhancement with BSR Support Added
      • BGP neighbor naming support
      • Increased AS path item for BGP route maps
      • IPv6 PCP support for DNAT46 in NAT64 deployments
      • Customizable CoS marking for locally generated ARP packets
      • Firewall address support for IPAM rules
      • Graceful BGP shutdown
      • TCP congestion control enhancement with BBR
      • Session helper statistics
