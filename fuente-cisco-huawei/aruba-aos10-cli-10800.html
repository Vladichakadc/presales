What's New in AOS 10.8.0.0

This section lists the commands introduced, modified, or deprecated in AOS 10.8.0.0.

New Commands in AOS 10.8.0.0

The following commands were introduced in AOS 10.8.0.0.

Command

Description

show ap debug ble-server request-log

This command is used to display the debug logs.

show ap debug ble-server request-hash

This command refers to the use of hash function within the BLE server implementation.

ap debug ble-server summary

This command displays the summary of the BLE server running on an AP.

show ap debug ble daemon ap iot connector apps display

This command is used to display information about IoT applications connected to the Access Point (AP) through the BLE daemon and IoT connector.

show ap debug ble daemon ap iot connector apps stats

This command provides statistics related to IoT connector data, including incoming and processed tag messages.

ble-init-action ap-connector app-debug

This command is used to initiate a specific debugging action related to the AP connector and application functionality for Bluetooth Low Energy (BLE) operations.

show ap debug ble server

This command displays statistics and details about Bluetooth Low Energy (BLE) devices and beacons detected by an Access Point (AP).

show datapath ipv6 session dpi

This command is used to check the Application Classification for IPv6 sessions.

show datapath ipv6 firewall-agg-sess

This command is used to verify aggregated DPI statistics for applications on an AP.

show dpi-classification-cache ipv6

This command displays the current state and contents of the DPI classification cache specifically for IPv6 traffic.

show apptag license-state

This command displays the current license status for the AppTag functionality on an AP.

show datapath apptag license-state

This command displays the current license status for AppTag (application classification/tagging) on the datapath of an AP.

show syslog server

This command displays all the Syslog server information.

show interface port-channel

This command displays the details of a specified port channel interface.
